# Blind

## Inventory capture app

A mobile-friendly inventory capture prototype that lets you open a camera feed, take photos or record short videos, and add them to an inventory list.

### Run locally

Open `app/index.html` in a modern browser (mobile preferred) and allow camera access.
Use **Export to Excel (CSV)** to download a CSV that lists item name, product number, vendor,
and price for use in Excel or vendor price sheets.
